# refractivelabs.com

Static marketing site for Refractive Labs, hosted on GitHub Pages.

- `index.html` — the single-page site
- `assets/style.css` — styles
- `assets/optics.js` — scroll-driven refraction animation (Snell, Cauchy dispersion, Fresnel)
- `assets/favicon.svg` — favicon / logo mark
- `CNAME` — custom domain for GitHub Pages (do not delete)
- `.nojekyll` — serve files as-is, no Jekyll processing

## Editing

Edit the HTML/CSS directly and push to `main`. GitHub Pages redeploys automatically within a minute or two.

## Local preview

```
python3 -m http.server 8000
```

Then open http://localhost:8000.
